01Quickstart

Generate your first voiceover in 30 seconds. Get a key from the API console (Pro & Business plans), then:

curl -X POST https://www.dethe.in/api/v1/tts \
  -H "Authorization: Bearer dth_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "नमस्ते! यह DetheAI की आवाज़ है।",
    "voice": "priya",
    "languageCode": "hi-IN"
  }' | jq -r .audioBase64 | base64 -d > voice.mp3

02Authentication

Every request needs your API key in the Authorization header. Keys are issued instantly on the API console after upgrading to Pro or Business.

Authorization: Bearer dth_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

🔒 Keep your key secret — anyone holding it can spend your credits. Revoke & reissue anytime from the console.

03Endpoints

MethodEndpointWhat it does
POST/api/v1/ttsText → speech (returns base64 MP3)
GET/api/v1/voicesAll 37 voices + 11 languages (no auth)

POST/api/keys/infoCheck key balance & expiry
POST/api/keys/revokePermanently delete a key

05Credits & limits

💎 Same credit economy

500 credits per 100-word block (min 500/request). Pro = 50,000/month, Business = 200,000/month — credits refill automatically every 30 days.

📏 Per request

Max 3,000 characters. Keys stay valid while your plan is active (monthly = 30 days, yearly = 365 days).

🛟 Failed = free

If synthesis fails, credits are auto-refunded. You only pay for audio you actually receive.

07Code samples

JavaScript

const r = await fetch(
  "https://www.dethe.in/api/v1/tts",
  {
    method: "POST",
    headers: {
      Authorization: "Bearer dth_live_KEY",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      text: "Welcome to DetheAI!",
      voice: "aditya",
      languageCode: "en-IN",
    }),
  }
).then((x) => x.json());

const audio = new Audio(
  "data:" + r.mimeType +
  ";base64," + r.audioBase64
);
audio.play();

Python

import requests, base64

r = requests.post(
    "https://www.dethe.in/api/v1/tts",
    headers={"Authorization":
             "Bearer dth_live_KEY"},
    json={
        "text": "नमस्ते दोस्तों!",
        "voice": "priya",
        "languageCode": "hi-IN",
    },
).json()

with open("voice.mp3", "wb") as f:
    f.write(base64.b64decode(
        r["audioBase64"]))
