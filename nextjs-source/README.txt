DetheAi intro — frame sequence
==============================

Drop your exported animation frames into this folder, e.g.

  frame_0001.jpg
  frame_0002.jpg
  ...
  frame_0240.jpg

Any names work (png / jpg / webp / avif). They are sorted naturally
(frame_2 comes before frame_10). Then open /intro — the page detects
the frames automatically and scrubs through them as you scroll.

If the folder is empty, /intro falls back to the built-in recreation
of the animation.
